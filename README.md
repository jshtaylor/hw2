Added TimeCode files, these can convert number of seconds into time in the hr:min:sec format. Once in this for can do basic arithmetic with them, this is later used in both the NasaLaunchAnalysis and the PaintDryTimer to store data

NasaLaunchAnalysis reads a CSV file and isolate and compiles the launch times to get an average launch time. Data stored in the timecode data type

Paint Dry Timer generates the amount of time needed for a painted sphere to dry based in the surface area of the sphere, numbers are once again using timecode data structure as well as a struct to store information of the particular sphere
